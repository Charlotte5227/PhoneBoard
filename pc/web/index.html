はじめての接続

  1. スマホとPCを同じWi-Fi（LAN）につなぎます。初回はWindowsのファイアウォール確認が出たら「プライベート ネットワーク」を許可してください。
  2. スマホで PhoneBoard を開き「PCを探す」→ 見つかったPCを選ぶ（見つからない時は上のアドレスを入力）。
  3. 上のPINを入力して「接続」。一度つながれば次回からは自動で接続します。

使い方（スマホは横向き・両手の親指で）

  • 切り替え: 画面左上の角のボタン、または音量↑で マウス ⇔ キーボード。
  • キーボード: 指を置くと、PC画面のキーボードで指の位置とキーが光ります。離した時に入力（置いたまま滑らせて位置を直せます）。最上段の空いた所へ指を逃がして離すと取り消し。
  • Shift / Ctrl / Alt / Win / Fn: 1回押すと次のキーにだけ効き、2回で固定、もう1回で解除（押さえたまま他のキーを押す同時押しも可）。「キーボード」タブで「押している間だけ」方式に変えられます。
  • Fn + 数字 = F1〜F12、Fn + 矢印 = Home/End/PgUp/PgDn、Fn + BS = Delete、Fn + Ctrl = CapsLock。
  • マウス: 右側のパッドでカーソル移動・タップで左クリック、2本指でスクロール。左端の縦長ボタンが左クリック/右クリック（押したままにするとドラッグ）、右端の帯でもスクロール。
  • 音量↓: マウス中は左ボタン（押している間）、キーボード中は 半角/全角。

全般

音の試聴

英字・数字などのボタンは、キーボードの左端→右端の高さで5回鳴ります（左が低く、右が高い）。

音で確かめる仕組み

キーごとの音: 母音（a i u e o）は明るい「ピッ」、子音などの英字は打鍵音、数字・記号は木の音、Space・Enter・BSは低い音、Esc・矢印などは「カチカチ」。さらに左のキーほど低く、右のキーほど高く鳴ります。
注意音（ポッポッ）: 日本語入力中に「kt」のようなローマ字として成り立たない並びになった時と、英字入力のままローマ字の日本語らしきものを打ち始めた時（一度だけ。IMEをONにするか別のアプリに切り替えると、また鳴ります）。さらに、日本語として極端に珍しいかなの並び（例:「たゔぇ」「きゅお」）になった時も、変換・確定・句読点までに1回だけ鳴ります（「わらし」のような、かなとしては自然な打ち間違いは拾えません）。

打ちミスを減らす仕組み

タッチ位置の自動補正: 「いつもキーの少し下を押している」などのクセを、左手側・右手側それぞれで打ちながら学習して補正します。打った直後にBSで消したキーは打ち間違いとみなして学習しません。
離す瞬間のズレ: 指を離す瞬間に指先が転がって隣のキーに乗っても、直前まで乗っていたキーを入力します。

入力補助について

初代iPhoneのように、次に来そうな文字のキーの当たり判定を見えない形で少し広げます。日本語入力中（IMEがON）はローマ字として成立する並び（例: k の次は母音）、英字入力中は英単語として自然な並び（例: th の次は e）を優先します。キーの真ん中をしっかり押した時は補正しません。入力した後で書き換えないので、変換の邪魔にはなりません。

方向入力は画面を見ずに打つための入力方法です。左右どちらの半分も、触れる場所は自由で、はじいた方向だけで決まります。

日本語: 左の親指で行（↖か ↑さ ↗た ←な トンは →ま ↙や ↓ら ↘わ）、右の親指で段（トンあ ←い ↑う →え ↓お）。右の ↖ん ↗変換 ↙濁点・小文字 ↘数字へ（そのまま左へ引くと英字へ）。右を長く引く: ←削除 ↓確定。
行を選んでから右 ↖/↙ で記号（か「」 さ【】 た…： な〜 は？！ ま（） や→← ら♪ わｗ（笑））。わ行の い・う・え は 、。・、や行の い は ー、え は 空白。
変換中: 右 ↓次の候補 ↑前の候補 →確定 ←取り消し、左 ←→ で区切りを動かす。

数字: 左の親指はテンキー（トン5、↖1 ↑2 ↗3 …）、右の親指はトン0、↑. ↓, ←- →+ ↖/ ↗: ↙%。右 ↘ で日本語へ。
英字: 画面のどこにでも一筆書き。もう片方の指で押さえたまま書くと大文字。両手の親指で同時にトンで日本語へ。見本は練習ページ（GitHub Pages）で作れます。

記号のうち【】♪ｗ（笑）は日本語入力を通さずに直接入れるので、入力途中の文字が先に確定されることがあります。

ゲーム画面はスマホの左側に WASD などのキー、右側に視点を動かすパッドとクリックボタンが並ぶ画面です。視点パッドをトンと叩くと左クリックです。キーもクリックボタンも押している間ずっと押しっぱなしになり、複数同時に押せます。配置は「マウス・ゲーム画面」タブで「ゲーム画面」を選ぶと変えられます。ボタンのアクションに {W} や {LSHIFT} のようにキーを書くと、そのキーを押しっぱなしにします。

普通のキーボード画面をゲームで使う時は「キーボード」タブの「キーを入力するタイミング」を「押している間押しっぱなし」にしてください。

反応しない時: 管理者として動いているゲームには、PCソフトも右クリック→「管理者として実行」で起動しないと入力が届きません。また、チート対策（アンチチート）が仮想入力を拒否するゲームでは使えません。

その他

スマホの音量ボタンに割り当てる動作です（下の「キー名・アクション一覧」の書式）。クリック系は押している間ボタンを押しっぱなしにします。

領域をクリックで選択

パッド=カーソル移動（タップでクリック、2本指でスクロール）、スクロール=なぞってスクロール、ボタン=触れて離すとアクション（クリック系・キー1つは押している間押しっぱなし）、視点=ゲームの視点操作（なぞった分だけマウスを動かす。トンと叩くと左クリック）。画面の端は見なくても指で探せるので、端に配置するのがおすすめです。

送るキーの名前

A〜Z, 0〜9, F1〜F24 と下の名前が使えます。「ボタン」タブなどでは {CTRL+SHIFT+Z} のように {} で囲み、修飾キー(CTRL/SHIFT/ALT/WIN)を + でつなげます。
