# PhoneBoard

スマホ（Android）を、PC用の **マウスパッド＋日本語配列キーボード** にするソフトです。
「寝ながらVRに映したPC画面を、**スマホを見ずに** 操作する」ことを目的に作っています。

- スマホ: `PhoneBoard.apk`（Android 5.0 以降・**横向き専用**）
- PC: `PhoneBoard.exe`（Windows 10 / 11、インストール不要・単体exe）

## しくみ

スマホは「どこを触っているか」を送るだけで、キーの判定・入力補助・表示はすべてPC側で行います。
そのため **PC画面（VR）を見るだけで、今どこに触れていて、何が入力されるか** がわかります。

## はじめかた

1. PCで `PhoneBoard.exe` を起動します（タスクトレイにアイコンが出て、設定画面がブラウザで開きます）。
   - 初回に Windows のファイアウォール確認が出たら **プライベート ネットワーク** を許可してください。
   - SmartScreen の警告が出た場合は「詳細情報」→「実行」。
2. スマホに `PhoneBoard.apk` をインストールします（「提供元不明のアプリ」の許可が必要です）。
3. スマホとPCを同じWi-Fiにつなぎ、アプリで「同じWi-FiのPCを探す」→ PCを選ぶ → 設定画面に表示されている **PIN** を入力 →「接続する」。
4. 一度つながれば、次回からは起動するだけで自動接続します（PCのIPが変わっても名前で探し直します）。

## 操作（横向き・両手の親指で）

| 操作 | 動作 |
|---|---|
| 左上の角のボタン / 音量↑ | マウス ⇔ キーボード 切替 |
| 音量↓ | マウス中: 押している間 左ボタン押しっぱなし / キーボード中: 半角/全角 |
| 3本指で2秒押さえる / 戻る | 接続設定画面 |

（音量キーの割り当ては設定画面「ボタン」タブで変更できます）

### キーボード（日本語配列・テンキーレス）
```
[マウス]                                         [Del]
Esc 1  2  3  4  5  6  7  8  9  0  -  ^  ¥  BS
Tab  Q  W  E  R  T  Y  U  I  O  P  @  [  Enter
Ctrl  A  S  D  F  G  H  J  K  L  ;  :  ]
Shift  Z  X  C  V  B  N  M  ,  .  /  \  ↑  Shift
Fn 半/全 Win Alt 無変換 Space 変換 かな ←  ↓  →
```
- 指を置くと、PC画面のキーボードで **指の位置（赤い点）** と **その下のキー（黄色）** が光ります（両手分）。
- **離した時に入力** します。置いたまま滑らせて位置を直せます。最上段の空いた所へ指を逃がして離すと **取り消し**。
  （設定で「触れた瞬間に入力」にも変えられます）
- 入力したキーは一瞬緑に光り、クリック音が鳴ります（PC・スマホ・両方・なしを選べます）。
- BS・矢印・Delは押し続けるとリピートします（なぞって来て止めた時はリピートしません）。
- **Fn**: Fn + 数字 = F1〜F12、Fn + 矢印 = Home/End/PgUp/PgDn、Fn + BS = Delete、Fn + ¥ = PrintScreen、Fn + Ctrl = CapsLock、Fn + Win = アプリケーションキー。
- かなは普通のキーボードと同じく PC の IME（ローマ字入力）で入力・変換します。PC画面左上に IME の状態（あ / A）が出ます。

### 音と表示で確かめる（目と触覚が使えなくても）
- **キーごとの音**: 種類で音色が変わり（母音 a i u e o は明るい「ピッ」、子音などの英字は打鍵音、数字・記号は木の音、Space・Enter・BS は低い音、Esc・矢印などは「カチカチ」、Shift・Ctrl などは小さな「カチッ」）、さらに **左のキーほど低く、右のキーほど高く** 鳴ります。
- **注意音（ポッポッ）**:
  - 日本語入力中に、ローマ字として成り立たない子音の並び（例: `kt` `sd`）になった時
  - 英字入力のまま、ローマ字の日本語らしきもの（例: `konnnitiwa`）を打ち始めた時（6文字目あたりで一度だけ。そのまま打ち続けた場合は「わざと」とみなして鳴らしません。IMEをONにするか、別のアプリに切り替えると、また鳴ります）
- **中央表示**: 入力したキーを、画面中央に一瞬うっすら表示します（注意の時は赤）。
- 設定画面「キーボード」タブで各音を試聴できます。音はPC・スマホ・両方・なしから選べます。

### 打ちミスを減らす仕組み
- **タッチ位置の自動補正**: 「いつもキーの少し下を押している」などのクセを、左手側・右手側それぞれで打ちながら学習して補正します（打った直後にBSで消したキーは学習しません）。設定画面でリセットできます。
- **離す瞬間のズレ対策**: 指を離す瞬間に指先が転がって隣のキーに乗っても、直前まで乗っていたキーを入力します。

### Shift・Ctrl・Alt・Win・Fn（設定「キーボード」で切替）
- **ワンショット（既定）**: 1回押すと次のキーにだけ効きます。2回押すと固定、もう1回で解除。押さえたまま他のキーを押す同時押しもできます。PC画面では 黄=次の1回、緑=固定、青=押さえている、で表示。
- **同時押し**: 普通のキーボードと同じく、押している間だけ効きます（Alt を押さえたまま Tab を何度も押すウィンドウ切替なども可）。

### 入力補助（初代iPhone風）
次に来そうな文字のキーの当たり判定を、見えない形で少し広げます。
- 日本語入力中（IME ON）: ローマ字として成立する並びを優先（例: k の次は母音）
- 英字入力中（IME OFF）: 英単語としてよく使われる並びを優先（例: th の次は e）

キーの真ん中をしっかり押した時は補正しません。入力した後で書き換えないので、変換の邪魔になりません。強さは設定で調整・オフにできます。

### マウス（既定の画面配置）
```
┌────────┬───────────────────────────┬────┐
│キーボード│                           │ ス │
├────────┤                           │ ク │
│左クリック│       パッド               │ ロ │
├────────┤                           │ ー │
│右クリック│                           │ ル │
└────────┴───────────────────────────┴────┘
```
- パッド: なぞる=カーソル移動 / タップ=左クリック / 2本指でなぞる=スクロール / 2本指でトン=右クリック / ダブルタップしてそのままなぞる=ドラッグ
- 左端のボタンは押している間ボタンを押しっぱなし → **左手で左クリックを押さえたまま、右手でパッドをなぞるとドラッグ**
- 右端の帯: なぞってスクロール（はじくと慣性）
- 触れた時の振動: スクロール帯=1回、ボタン=2回。PC画面の隅に小窓で触れている位置も表示されます。

## 設定（PCのブラウザ）

タスクトレイのアイコンをクリックすると開きます（`http://127.0.0.1:39501/`。PC内からのみアクセス可能）。

- **キーボード**: 入力のタイミング、修飾キーの方式、入力補助の強さ、リピート、クリック音（PC/スマホ/両方/なし・音量）
- **PC表示**: 画面の縮図の上でキーボード表示をドラッグして配置、大きさ・透明度
- **キー配置**: キーをクリックで選び、表示・送るキー・Fn時のキー・位置・大きさを編集（ドラッグで移動）。保存するとすぐスマホとPC表示に反映。ファイルへの書き出し/読み込みも可。
- **マウス画面**: パッド・スクロール帯・ボタンの位置と動作
- **マウス / 振動 / ボタン**: 速度、振動の強さ、音量キーの割り当てなど

設定ファイルは `%APPDATA%\PhoneBoard\`（`config.json`, `layouts.json`）に保存されます。

## うまくいかない時

- **PCが見つからない**: 同じWi-Fiか、ファイアウォールで許可したか確認。ゲスト用Wi-Fiなど端末同士の通信が禁止されたネットワークでは使えません。IPアドレス（設定画面「接続」タブに表示）を直接入力してもつながらない場合は、ファイアウォールで TCP/UDP 39500 を許可してください。
- **接続が切れやすい・カーソルがカクつく**: カーソル移動とスクロールは、Wi-Fiで一瞬途切れても止まりにくいUDPで送っています（ファイアウォールで UDP 39500 も許可が必要。初回の許可で通常は両方許可されます）。それでも気になる時は、スマホとPCをできるだけ5GHzのWi-Fiに。ルーターの「プライバシーセパレーター／AP分離」がオンだとつながりません。
- **記号がずれる**: Windows のキーボード設定を「日本語キーボード（106/109キー）」にしてください。
- **管理者として実行中のアプリを操作できない**: Windowsの仕様です。PhoneBoard.exe も管理者として実行してください。
- **PC側のキーボード表示が見えない**: フルスクリーン専用モードのゲーム上には表示できません（ボーダーレスウィンドウなら表示されます）。

## ビルド

Linux（Ubuntu 24.04）で両方ビルドできます。Gradle や Android Studio は不要です。

```sh
# Android SDK の android.jar (API 30〜34) を ANDROID_HOME か ANDROID_JAR で指定
sudo apt install golang aapt apksigner zipalign dalvik-exchange default-jdk-headless binutils-mingw-w64-x86-64
./build.sh      # → dist/PhoneBoard.exe, dist/PhoneBoard.apk
```

GitHub に push すると `.github/workflows/build.yml` で自動ビルドされ、`v*` タグを付けるとリリースが作られます。
APK署名用の鍵 `android/phoneboard.keystore` はリポジトリに含めています（同じ鍵で署名しないと上書きインストールできないため。個人利用向けの簡易鍵です）。

## 構成

```
pc/        PCソフト（Go、外部ライブラリなし）
  kbd.go          キーボードの判定（複数の指・修飾キー・リピート）
  assist.go       入力補助（ローマ字・英単語の続きやすさ）
  layout.go       既定のキー配置・マウス画面
  keys.go         キー名と仮想キーコード（日本語配列）
  app.go          全体の制御・マウス処理
  sound.go        クリック音の合成
  server.go       スマホとの通信（TCP/UDP 39500）
  web.go, web/    設定画面
  overlay_windows.go  PC画面のキーボード表示・タスクトレイ
  platform_windows.go SendInput / IME状態の取得
android/   スマホアプリ（Java）
tools/fakephone.py  通信テスト用の模擬スマホ
```
