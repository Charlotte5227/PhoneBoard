# PhoneBoard

スマホ（Android）を、PC用の **マウスパッド＋フリックキーボード** にするソフトです。
「寝ながらVRに映したPC画面を、**スマホを見ずに・親指1本で** 操作する」ことを目的に作っています。

- スマホ: `PhoneBoard.apk`（Android 5.0 以降）
- PC: `PhoneBoard.exe`（Windows 10 / 11、インストール不要・単体exe）

## しくみ

```
 スマホ（見ない）                         PC（VRで見る）
 ┌────────────┐   Wi-Fi(LAN)   ┌──────────────────────────┐
 │ 画面全体が  │ ─────────────▶ │ マウス操作・キー入力を実行 │
 │ タッチ面    │   触れた位置    │ キーボード画面を表示し、   │
 │ 音量キー    │ ◀───────────── │ 指の位置・キーを光らせる   │
 │ 振動        │   振動の指示    │ 設定画面（ブラウザ）      │
 └────────────┘                 └──────────────────────────┘
```

スマホは「どこを触っているか」を送るだけで、キーの判定と表示はすべてPC側で行います。
そのため **PC画面（VR）を見るだけで、今どこに触れていて、何が入力されるか** がわかります。

## はじめかた

1. PCで `PhoneBoard.exe` を起動します（タスクトレイにアイコンが出て、設定画面がブラウザで開きます）。
   - 初回に Windows のファイアウォール確認が出たら **プライベート ネットワーク** を許可してください。
   - SmartScreen の警告が出た場合は「詳細情報」→「実行」。
2. スマホに `PhoneBoard.apk` をインストールします（「提供元不明のアプリ」の許可が必要です）。
3. スマホとPCを同じWi-Fiにつなぎ、アプリで「同じWi-FiのPCを探す」→ PCを選ぶ → 設定画面に表示されている **PIN** を入力 →「接続する」。
4. 一度つながれば、次回からは起動するだけで自動接続します（PCのIPが変わっても名前で探し直します）。

## 操作（親指1本・スマホは見ない）

### 共通
| 操作 | 動作 |
|---|---|
| 音量↑ | マウス ⇔ キーボード 切替 |
| 音量↓ | マウス中: 押している間 左ボタン押しっぱなし（ドラッグ用）/ キーボード中: かな→ABC→123 切替 |
| 画面左上隅を2秒長押し | 接続設定画面 |

（音量キーの割り当ては設定画面「ボタン」タブで変更できます）

### マウス（既定の画面配置・右手用）
```
┌───────────────┬────┐
│               │ ス │
│   パッド      │ ク │   パッド: なぞる=カーソル移動 / タップ=左クリック
│               │ ロ │           ダブルタップしてなぞる=ドラッグ
│               │ ー │   右端の帯: なぞる=スクロール（はじくと慣性）
│               │ ル │
├────┬────┬─────┴────┤
│キー│左右│ 右クリック │  ← 画面の下端なので指で探せます
│ボード│切替│            │
└────┴────┴──────────┘
```
- **タップは左クリック固定**、右クリックは専用ボタン。
- 「左右切替」を押すと、次のタップが右クリックになります（1回で左に戻る／設定で固定にも可）。
- 長押しを右クリックやドラッグに割り当てることもできます（設定「マウス」）。
- 触れると振動します（スクロール帯=短く1回、ボタン=2回）。PC画面の右下に小窓で触れている位置も表示されます。

### キーボード（探って・止めて・はじく）
1. 指を置いてなぞると、PC画面のキーボードに **指の位置（赤い点）** と **その下のキー（黄色）** が表示されます。キーをまたぐたびに短く振動します。
2. 目的のキーで **指を止める** と振動して緑になります（確定待機）。上下左右の候補が十字に大きく表示されます。
3. **はじいた方向** の文字が、**指を離した時** に入力されます（方向が変わるたびに振動）。
4. 止める前に離すと **取り消し**（何も入力されない）。確定待機後に大きく動かすと探し直せます。
5. 慣れたら、置いてすぐはじいて離す普通のフリックもそのまま使えます。

- かなは **IMEにローマ字として送る** ので、Windowsの漢字変換がそのまま使えます（空白キー=変換、改行=確定、空白キーを上フリック=カタカナ(F7) など）。
- 「゛゜小」キー: タップで直前の文字を 濁点→半濁点→小文字 と切替。英字配列の「a/A」は大文字小文字切替。
- 「削除」は長押しでリピート。「←」「→」キーは上下フリックで↑↓、外側フリックで先頭/末尾。
- 「編集」キー: タップ=貼り付け、上=コピー、左=切り取り、右=全選択、下=元に戻す。

## 設定（PCのブラウザ）

タスクトレイのアイコンをクリックすると開きます（`http://127.0.0.1:39501/`。PC内からのみアクセス可能）。

- **キー配列**: キーをクリックして選び、表示・各方向の出力・位置・大きさを編集。ドラッグで移動。列数/行数、キーボードの位置（右手寄せ/左手寄せ等）、左右反転、配列の追加も可能。保存するとすぐスマホに反映されます。
- **マウス画面**: パッド・スクロール帯・ボタンの位置と動作を編集（左手用への反転ボタンあり）。
- **マウス / キーボード / 振動 / PC表示 / ボタン**: 速度、確定待機までの時間、フリック距離、振動の強さ、PC側表示の位置・大きさ・透明度などを調整。
- キーやボタンには文字のほか `{ENTER}` `{CTRL+Z}` `{MODE:alpha}` などのアクションを指定できます（「アクション一覧」タブ参照）。

設定ファイルは `%APPDATA%\PhoneBoard\`（`config.json`, `layouts.json`）に保存されます。

## うまくいかない時

- **PCが見つからない**: 同じWi-Fiか、ファイアウォールで許可したか確認。ゲスト用Wi-Fiなど端末同士の通信が禁止されたネットワークでは使えません。IPアドレス（設定画面「接続」タブに表示）を直接入力してもつながらない場合は、ファイアウォールで TCP/UDP 39500 を許可してください。
- **管理者として実行中のアプリを操作できない**: Windowsの仕様です。PhoneBoard.exe も管理者として実行してください。
- **かなが英字のまま入力される**: 設定「キーボード」の「IMEのON/OFFを自動で合わせる」をオンに。うまくいかないアプリでは「ひらがなを直接送る」に切り替えると確実に入ります（漢字変換は不可）。
- **PC側のキーボード表示が見えない**: フルスクリーン専用モードのゲーム上には表示できません（ボーダーレスウィンドウなら表示されます）。

## ビルド

Linux（Ubuntu 24.04）で両方ビルドできます。Gradle や Android Studio は不要です。

```sh
sudo apt install golang android-sdk-platform-23 aapt apksigner zipalign dalvik-exchange default-jdk-headless binutils-mingw-w64-x86-64
./build.sh      # → dist/PhoneBoard.exe, dist/PhoneBoard.apk
```

GitHub に push すると `.github/workflows/build.yml` で自動ビルドされ、`v*` タグを付けるとリリースが作られます。
APK署名用の鍵 `android/phoneboard.keystore` はリポジトリに含めています（同じ鍵で署名しないと上書きインストールできないため。個人利用向けの簡易鍵です）。

## 構成

```
pc/        PCソフト（Go、外部ライブラリなし）
  engine.go       片手フリックの判定（探る・止める・はじく）
  typist.go       文字→キー入力（IMEローマ字・濁点切替など）
  app.go          全体の制御・マウス処理
  server.go       スマホとの通信（TCP/UDP 39500）
  web.go, web/    設定画面
  overlay_windows.go  PC画面のキーボード表示・タスクトレイ
  platform_windows.go SendInput / IME制御
android/   スマホアプリ（Java）
tools/fakephone.py  通信テスト用の模擬スマホ
```

通信は改行区切りのJSONです（スマホ→PC: `hello` `kt`(キーボードのタッチ) `mm`(移動) `ms`(スクロール) `tap` `mb` `btn` `hw`(音量キー) …、PC→スマホ: `cfg` `setmode` `state` `vib` …）。
