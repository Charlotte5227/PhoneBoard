はじめての接続

  1. スマホとPCを同じWi-Fi（LAN）につなぎます。初回はWindowsのファイアウォール確認が出たら「プライベート ネットワーク」を許可してください。
  2. スマホで PhoneBoard を開き「PCを探す」→ 見つかったPCを選ぶ（見つからない時は上のアドレスを入力）。
  3. 上のPINを入力して「接続」。一度つながれば次回からは自動で接続します。

使い方（スマホは見ずに、親指1本で）

  • 音量↑: マウス ⇔ キーボード 切替（「ボタン」タブで変更可）
  • マウス: パッドをなぞる=カーソル移動 / タップ=左クリック / 右端の帯=スクロール / 下段=キーボード・左右切替・右クリック。音量↓を押している間は左ボタンを押しっぱなし（ドラッグ用）。
  • キーボード（既定）: スマホのキーボード（Gboard等）がそのまま開きます。変換中の文字はPC画面に大きく表示され、確定するとPCに入力されます。Gboardの「変換」キーで候補を切り替えると、PC画面の表示も切り替わります。キーボードを閉じる（戻る）とマウスに戻ります。キーボードの上に見えている部分はマウスパッドです。
  • キーボード（PhoneBoardフリック、設定で切替）: 指を置いてなぞると、PC画面のキーボードで指の位置と、その下のキーが光ります（キーをまたぐと振動）。そのまま離すとそのキー、最後にはじいて離すとフリック文字が入力されます。PC画面右上に「離すと ○」と、入力される文字が出ます。やめる時はキーボードの外（上）へ指を出してから離します。
  • 変換: 右列の「変換」キーで漢字変換（もう一度で次の候補）、「改行」で確定。「変換」キーを左右にはじくとカーソル移動。
  • スマホ画面の左上隅を2秒長押しすると接続設定画面に戻ります。

全般

入力方式

かんたん: なぞって探す → 離すとそのキー / 最後に素早くはじくとフリック文字。キーボードの外で離すと取り消し。待ち時間なし。
確実: なぞって探す → 指を止める（振動・緑）→ はじいて離す。止める前に離すと取り消し。
普通のフリック: スマホの通常のフリック入力と同じ。

マウスモード時のスマホ画面の区分けです。パッド=カーソル移動（タップでクリック）、スクロール=なぞってスクロール、ボタン=触れて離すとアクション（クリック系は押している間押しっぱなし）。画面の端は見なくても指で探せるので、端に配置するのがおすすめです。

選択中の領域

キーやボタンには文字のほか、{名前} の形でアクションを指定できます。{CTRL+SHIFT+Z} のように修飾キー(CTRL/SHIFT/ALT/WIN)も組み合わせられます。
